# Self AI - Open Source AI Psychologist Real-Time Conversation

### Welcome to Self AI
This repository contains the backbone of Self AI platform, offered open sourced without any restrictions in order to advance technological advancement and the benefits of human psychology.

### What you'll find
This repository contains:
- An experimental user interface featuring 3D avatar interactions, voice and text communication powered by emotion detection, gestures and micro expressions.
- Integrations with various APIs such as TTS, Voice Emotion Detection, PineCone VDB and more.
- Low-latency WebRTC solution for quick real-time voice communication.
- Ultra high quality 3D model, containing animations for gestures and micro expressions.
- Ability to generate background images, retain memories and more.

### Disclaimer
The point of making this work public is to make scientific knowledge more wide-spread. Please use this work for the advancement of human kind rather than more nefarious activities.
